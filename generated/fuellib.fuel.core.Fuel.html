fuellib.fuel.core.Fuel

class fuellib.fuel.core.Fuel(name, data_dir=None, *, use_ref_props=True, fuelDataDir=None, useRefProperties=None)

Bases: object

Class for handling calculations of thermodynamic and mixture properties.

Initialize a Fuel instance.

Parameters:

  • name (str) – Name of the fuel.

  • data_dir (str | Path | None) – Directory containing fuel data. Defaults to fuelLib/data.

  • use_ref_props (bool) – Whether to use reference compound properties for calculations. Defaults to True.

  • fuelDataDir (str | Path | None) – Deprecated alias for data_dir.

  • useRefProperties (bool | None) – Deprecated alias for use_ref_props.

Raises:

  • FileNotFoundError – If the fuel data directory does not exist.

  • ValueError – If the GCxGC data file is missing required columns.
